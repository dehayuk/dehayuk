Kebijakan privasi Dehayuk

Penghapusan Data Dehayuk

Dehayuk menyediakan penghapusan sebagian data pemain melalui fitur Hapus profil gelanggang. Fitur ini tidak menghapus seluruh data yang dikumpulkan aplikasi.

Cara menghapus profil Gelanggang

  1. Buka Dehayuk pada perangkat dan penyimpanan browser yang digunakan untuk bermain, lalu masuk ke Gelanggang.
  2. Tekan avatar pemain untuk membuka Profil Gelanggang.
  3. Pilih Hapus profil gelanggang, kemudian konfirmasikan dengan memilih Hapus.
  4. Tunggu pesan Profil gelanggang dihapus. Koneksi internet diperlukan. Jika muncul pesan kegagalan, coba kembali.

Data yang dihapus

Profil Gelanggang, termasuk nama panggilan, nomor, avatar, pilihan bingkai dan lencana; tag nama; catatan pemain; prestasi; dan penghitung pemain. Data tersebut dihapus dari database aktif ketika permintaan penghapusan berhasil diproses.

Data yang tetap tersimpan

Tombol ini tidak menghapus skor dan progres di perangkat, papan peringkat, identitas autentikasi tamu, rekaman dan hasil pertandingan bersama, laporan pemain, kiriman Lapor & Saran, laporan error, atau data yang diproses Google AdMob.

Data lokal tetap tersimpan sampai penyimpanan aplikasi atau browser dibersihkan. Untuk data server yang tidak dihapus oleh tombol ini, Dehayuk belum menerapkan masa retensi tetap atau penghapusan otomatis dalam 90 hari; data dapat tetap tersimpan tanpa batas waktu otomatis yang ditetapkan. Penghapusan profil bukan permintaan penghapusan seluruh data tersebut.

Data yang diproses Google AdMob mengikuti Kebijakan Privasi Google.
